#### What are Browsers? How do they render Websites/Web Applications?

Browser - Client
Google/Facebook/YouTube etc. Websites - Servers

Browsers are used to communicate with a Server.
Server provides response in the form of HTML + CSS + JavaScript OR JSON OR XML OR Audio OR Video OR Text etc.,
that Browser can understand and render in its window.

For example,
1. Open a Browser, for example Google Chrome.
2. Type https://google.com in the address bar, this is a request to Server at google.com.
3. Google Server then returns a response (home page), this is rendered in the Browser window.
4. User types a search string in the search box and hits enter,
   this is another request to Server at google.com.
5. Google Server then returns a response (search results), this is rendered in the Browser window.
and so on.

> Browser is a medium/interface to communicate with a Server.
